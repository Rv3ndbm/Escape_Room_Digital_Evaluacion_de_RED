# Directorio de Recursos Multimedia (assets/media/)

Este directorio contiene los recursos gráficos, vectores e imágenes de apoyo para el Escape Room Digital **"Misión: Salvar la Tierra"**.

### Rutas Recomendadas y Recursos:
- **Iconos de Misión / Tierra**: `assets/media/earth-planet.svg`
- **Avatares de Exploradores**: `assets/media/explorer-kids.svg`
- **Insignias de Desbloqueo**:
  - `assets/media/badge-volcan.svg` (Pertinencia)
  - `assets/media/badge-tsunami.svg` (Usabilidad)
  - `assets/media/badge-terremoto.svg` (Calidad)
  - `assets/media/badge-calor.svg` (Accesibilidad)

*Nota: La interfaz actual utiliza iconografía vectorial nítida con Font Awesome 6 CDN y animaciones CSS/Anime.js para garantizar carga ultrarrápida y cero dependencias de archivos pesados.*
